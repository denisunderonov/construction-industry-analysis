# Construction Industry Analysis

Проект по исследованию строительного рынка России на данных ФНС.

В этом проекте я взял реестр компаний с основным ОКВЭД 41.20 «Строительство жилых и нежилых зданий», подготовил данные для анализа, собрал дополнительную финансовую информацию и добавил географию компаний.

Основная задача проекта была пройти полный цикл аналитической работы: подготовить исходные данные, получить дополнительные признаки, объединить несколько источников, провести исследовательский анализ и представить результаты с помощью визуализаций.

## Задачи

В ходе работы я хотел ответить на несколько вопросов:

- сколько компаний попадает в выбранную выборку;
- как компании распределены по регионам;
- в каких регионах их больше всего;
- насколько сильно отличаются компании по финансовым показателям;
- какие компании выделяются по выручке и прибыли;
- как связаны между собой основные финансовые показатели;
- как выглядит географическое распределение компаний на карте.

## Данные

В качестве основного источника использован реестр субъектов малого и среднего предпринимательства ФНС.

Из исходного файла я оставил:

- юридические лица;
- субъекты малого и среднего предпринимательства;
- компании с основным ОКВЭД 41.20 «Строительство жилых и нежилых зданий».

Финансовые данные дополнительно получались из бухгалтерской отчётности через `bo.nalog.ru`.

Для географического анализа адреса компаний были преобразованы в координаты с помощью геокодирования.

## Стек

`Python` · `Pandas` · `NumPy` · `Matplotlib` · `GeoPandas` · `Requests` · `Geopy`

## Что я сделал

### 1. Подготовил реестр

Сначала загрузил большой исходный файл ФНС и отфильтровал его по типу организации, категории предприятия и основному виду деятельности.

После этого очистил необходимые поля и подготовил отдельный набор данных для дальнейшего анализа.

### 2. Собрал финансовые показатели

Для компаний из выборки получил дополнительные данные из бухгалтерской отчётности и объединил их с реестром ФНС.

В анализе использовал:

- выручку;
- прибыль до налогообложения;
- чистую прибыль;
- процентные расходы;
- EBIT.

EBITDA в проекте не рассчитывалась, так как в доступных данных не было достаточной информации для корректного восстановления амортизации.

### 3. Добавил географию

Адреса компаний геокодировал и получил координаты. Это позволило перейти от обычной группировки по регионам к визуальному анализу расположения компаний на карте.

### 4. Провёл исследовательский анализ

После подготовки данных сравнил регионы, финансовые показатели и отдельные компании. Для поиска закономерностей использовал таблицы, графики и карту.

## Основные выводы

В выбранной выборке компании распределены по России неравномерно. Отдельные регионы заметно выделяются по количеству организаций, поэтому строительная активность внутри рассматриваемой выборки распределена неодинаково.

Финансовые показатели также сильно отличаются между компаниями. В данных есть большое количество относительно небольших организаций и отдельные компании со значительно более высокими значениями выручки и прибыли. Из-за этого среднее значение не всегда хорошо описывает типичную компанию.

При сравнении выручки и прибыли видно, что большой оборот не означает автоматически такую же высокую чистую прибыль. Поэтому для анализа финансового положения одной выручки недостаточно, имеет смысл рассматривать несколько показателей одновременно.

Географический анализ показывает локальные концентрации компаний. Карта позволяет увидеть эту структуру более наглядно, чем обычная таблица с регионами.
